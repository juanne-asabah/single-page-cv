# Single-Page CV / Resume Layout

A clean, semantic and modern single-page CV template built explicitly following **HTML5 structural specifications** and polished with **custom CSS styling**. 

This project demonstrates foundational frontend principles including proper heading hierarchies, web accessibility standards, embedded **SEO Meta data**, and custom **Open Graph (OG)** protocols for professional social sharing.

## ✨ Core Features & Technical Elements Included
* **Semantic HTML5 Architecture**: Implements modern document structure standards using proper tags like `<article>`, `<div>` groupings, and separate inline `<address>` layouts.
* **Search Engine Optimization (SEO)**: Custom configured meta headers mapping your core page `keywords`, specialized indexing parameters (`robots`), and index descriptions.
* **Open Graph (OG) Protocols**: Built-in target properties ready to generate preview cards across professional networks like LinkedIn, Discord, and Slack.
* **Clean CSS Typography & Spacing**: Handcrafted internal CSS leveraging the fluid geometric `Trebuchet MS` typography stack, proper reading heights, and clean margins.
* **Device Accessibility Mapping**: Fully click-to-call (`tel:`) and click-to-email (`mailto:`) active anchor bindings.
* **Embedded SVG Favicon**: Lightweight, responsive tab emoji icon tracking (`💼`) initialized entirely inline without local asset files.

## 🛠️ Step-by-Step Desktop Initialization
To review the layout visually inside a standard desktop environment:
1. **Clone the Repo** or copy your local source code into a dedicated directory.
2. Locate the main **`cv.html`** file inside your file browser.
3. **Double-click** the file to execute the template directly inside your default web browser (Chrome, Edge, Safari, or Firefox).

## 📝 Configuration Updates Needed
Before hosting, update the following placeholder strings directly inside your `cv.html`:
* Modify the layout headlines replacing `Your Name` with your real name.
* Replace the mock link templates inside the `"Across the Internet"` section with your live, active LinkedIn and portfolio profile addresses.
