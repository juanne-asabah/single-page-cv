# Single-Page CV / Resume Layout

A clean, semantic, and highly optimized single-page digital CV built explicitly following modern **HTML5 semantic standards** and styled with **custom internal CSS layouts**. 

This repository serves as a fully functional solution to the foundational frontend challenge hosted on roadmap.sh.

- **Live Preview URL:** https://github.io

## ✨ Core Features & Technical Implementation

### 🏗️ Semantic HTML5 Architecture
- Built with standard structural elements using proper tags like `<article>`, `<div>` semantic wraps, and localized inline `<address>` layouts.
- Organized down a clear cascading heading ranking chain (`<h1>` → `<h2>` → `<h3>`) to align with universal web access standards.

### 🔍 Search Engine Optimization (SEO) & Social Graph Ready
- Embedded custom index configurations mapping targeted developer `keywords`, search summaries (`description`), and script crawler parameters (`robots`).
- Pre-configured with full **Open Graph (OG)** protocol metadata tags to instantly generate high-quality visual preview cards when sharing the portfolio on LinkedIn, Slack, or Discord.

### 🎨 Clean CSS Typography & Print Engineering
- Powered by a modern, fluid `Trebuchet MS` sans-serif typography stack configured for ideal baseline reading heights and consistent section margins.
- Features dynamic, accessible click-to-call (`tel:`) and click-to-email (`mailto:`) system links.
- Includes a dedicated **Print Stylesheet Media Query (`@media print`)** that automatically converts headers to crisp black, strips away web link buttons, and formats layout margins so recruiters can print or save it as a clean 1-page PDF.

### 💼 Inline Vector Favicon
- Utilizes a lightweight, zero-asset embedded SVG icon code within the header tab to inject a briefcase emoji vector without loading external image files.

## 🛠️ Local Desktop Initialization
To execute and modify the template layout on your personal machine:
1. Clone this repository or copy the code directory to your desktop.
2. Locate the main **`index.html`** file inside your file navigator.
3. Double-click **`index.html`** to execute the page directly inside your default web browser (Chrome, Edge, Firefox, or Safari).
